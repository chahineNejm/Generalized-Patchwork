Benchmarks (reference check: 2026-11-11)
GPW is our method; the following are comparison models, not completed runs.

Main comparisons
- SVGP (Hensman et al., 2013)
  Paper: https://arxiv.org/abs/1309.6835
  Paper-linked GitHub: https://github.com/SheffieldML/GPy
  
- Standard Patchwork Kriging (Park and Apley, 2018)
  Paper: https://jmlr.org/papers/v19/17-042.html
  Author GitHub: not verified. Our rectangular-region implementation is not authors' code.
  OISST comparison variants: checkerboard 4x2, GPW-initial-center Voronoi,
  and balanced first-PC tree with 8 regions. All use exactly the same GPW
  initial selected observations/targets. Tree stitches are seeded uniform draws.
  These reduced-data baselines do not see all observations used by GPW training.
  
- ProSpar-GP (Li and Mak, 2025)
  Paper: https://doi.org/10.1080/10618600.2025.2490264
  Author GitHub: not verified.
  Local: ProSparGP implemented from supplied arXiv v1 (6)-(13), with approved
  derived ELBO/prediction instead of literal printed (14)/(16); not author code.
  Supports arbitrary D and unequal expert budgets; Heaton/UKHousing adapters use
  equal budgets. Initial T_j, c, D_j and extra prior_jitter are required explicitly.
  
- VNNGP (Wu et al., 2022)
  Paper: https://proceedings.mlr.press/v162/wu22h.html
  GitHub: https://github.com/cornellius-gp/gpytorch
  Paper-linked example: https://docs.gpytorch.ai/en/stable/examples/04_Variational_and_Approximate_GPs/VNNGP.html

Aggregation/uncertainty diagnostic
- Nested Kriging (Rulliere et al., 2018)
  Paper: https://arxiv.org/abs/1607.05432
  Author-associated GitHub: https://github.com/drulliere/nestedKriging
  Repository association is from the authors' package announcement, not the supplied PDF.
  Local implementation: NestedKriging; two-layer shared-prior exact experts,
  arbitrary input dimension, RBF/Matern-5/2, explicit groups; no inducing variables.
  LOO-MSE fitting uses Adam rather than the paper's SPSA; noiseless scale calibration.
- PoE, gPoE, BCM, rBCM, smallest-variance, nearest-neighbor: diagnostic only; code links unverified.

Optional / undecided

  Paper: https://doi.org/10.1007/s10994-022-06297-3
  Paper-linked GitHub: https://github.com/manschuer/CPoE (returned 404).

  Paper: https://proceedings.mlr.press/v139/tran21a.html

Hyperparameters / Controls
M = total inducing points; P = patches/experts; m = points/expert;
B = batch size except in the Patchwork paper, where B = stitches/shared boundary.
Learned parameters are not fixed settings. NR = not reported in the checked source.

Model | Structural controls | Learned parameters
GPW | P, m, graph/neighbor count, stitches/edge, q_rank, train/freeze flags, weight_epsilon | local ARD lengthscales/output variances, shared noise SD, supports, independent stitches, q mean/block precision/low-rank factor; weights computed, not free parameters
SVGP | M, inducing initialization, train/freeze flags, covariance family | global ARD lengthscales/output variance, noise SD, inducing locations, q mean/full Cholesky
Standard Patchwork | partition, region size/count, stitches/boundary and placement | kernel lengthscales/output variance, observation noise; no variational q
ProSpar-GP | P, m, expert kernel family | expert kernel parameters/inducing locations, noise variance, inducing nuggets D_j, temperatures T_j, exponent c, variational parameters (preprint Sec. 3)
VNNGP | M, K neighbors, ordering, inducing initialization/fixed locations, batch sizes, covariance family | kernel parameters, likelihood noise, q mean/diagonal variance
Nested Kriging | partition/submodel count, aggregation tree, kernel family | shared kernel parameters if fitted; none fitted in the selected synthetic example
PoE/gPoE/BCM/rBCM/SPV/NN | expert data/layout/count; gPoE/rBCM weighting rule; NN neighbor count | expert kernel/noise parameters if fitted
CPoE (optional) | P, correlation order C, sparsity gamma, ordering/partition/predecessor rule | shared kernel/noise parameters; local inducing inputs need not be optimized
SWSGP (optional) | M, H active neighbors, fixed/learned inducing locations, full/diagonal q covariance | kernel/noise, inducing locations if enabled, variational parameters
Full GP (optional) | kernel/mean family, training subset | kernel/noise/mean parameters if fitted
Training controls: optimizer, learning rates, batch size, training budget, warm-up,
scheduler, stopping/selection rule, seeds. Numerical settings are separate from model parameters.

Our Current Colab Defaults (not new dataset prescriptions or completed results)
Shared: ARD RBF; initial lengthscales=0.1, output variance=1, noise SD=0.1;
100 epochs, kernel/noise frozen for first 20 in variational models; seed=31, float64, CUDA.
Adam: q LR=0.002; support/stitch/kernel/noise LR=0.001; GPW alternates q/structure steps.
GPW/SVGP: gradient clip=10, weight decay=0. No early stopping or LR scheduler.
Bounds: lengthscales (0.02,3), output variance (0.02,30), noise SD (1e-4,1).
Numerics: prior jitter=1e-4, minimum variational Cholesky diagonal=1e-3,
variance validity threshold=1e-12, GPW weight epsilon=0.01 (runner override of library 1e-8).

VNNGP paper - selected overlap: PROTEIN; Sec. 4.3 / Appendix D.3.1
M=N_train at observations, random ordering, mean-field q; K={32,256}.
Shared comparison setup: ARD Matern-5/2, Gaussian likelihood, Adam;
lengthscales/outputscale/likelihood-noise parameter initialized to 0.6931.
For Protein (<50k): iterations={300,500} x LR={0.005,0.01}; K adds two choices
(8 VNNGP combinations before seeds). LR drops x0.1 at 75% and 90% of budget.
64/16/20 split, 3 seeds; select by validation NLL. Winning settings per seed: NR.
SVGP comparator: M=1024, full covariance, k-means initialization (4 optimizer pairs).
SWSGP comparators: M=N_train OR M={1024,2048,4096,8192}, K={32,256}, mean-field;
learned-location version recomputes neighbors each epoch. Batch sizes: NR here.

For the existing UKHousing task (>50k), the paper's optimizer grid instead uses

Nested Kriging / aggregation - selected 1D Matern example, Sec. 5.1 / Figs. 4-5
N=30 uniform points in [0,1]; P=15 experts, two consecutive sorted points/expert;
zero-mean Matern-5/2, variance=1, lengthscale=0.05, held fixed (no fitting).
101 evenly spaced test points, 50 independent function/design replications.
Same experts for NK, PoE, gPoE, BCM, rBCM, SPV; full GP uses all 30 observations.
gPoE beta_i=1/15; rBCM beta_i(x)=0.5*log(prior_variance/local_variance_i(x));
SPV picks minimum variance. NN neighbor count: not explicit in checked 1D description.

gPoE original paper - SARCOS, Sec. 3 / Tables 1-2
P=512 experts, 256 observations/expert; independent ARD + white-noise kernels,
scaled conjugate-gradient hyperparameter fitting; entropy-change weights normalized.
Three constructions: random subsets, local neighborhoods, ball tree; plus tree-gPoE
using only root-to-leaf experts. Not the constant-beta NK diagnostic above.
Kernel/noise final values, initialization, iteration budget and repeat count: NR.
Paper: https://arxiv.org/abs/1410.7827
